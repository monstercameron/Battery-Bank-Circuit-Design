# Manufacturing (JLCPCB target)

Full capability tables and geometry rules: [jlcpcb-rules.md](jlcpcb-rules.html). Re-check JLCPCB's pages before ordering.

| Item | Choice |
|---|---|
| Layers | 6, impedance-controlled (USB 3 90 ohm, Ethernet and SerDes 100 ohm, RF 50 ohm) |
| Thickness | 1.6 mm |
| Copper | 2 oz outer, 1 oz inner |
| Finish | ENIG |
| Via-in-pad | Epoxy-filled and capped, under QFN thermal pads |
| Track / space | 0.10 mm inner, 0.16 mm on 2 oz outer |
| Assembly | Standard PCBA, SMT top side where possible, connectors THT |
| Fiducials | 3 global on the board plus local ones near the fine-pitch QFNs |
| Passives | Basic / Preferred parts to avoid Extended fees |
| Stock rule | JLCPCB stock at least 5x the build quantity at order time |

Programming is in-system through debug pads, so JLCPCB pre-programming is not required.
